# Petra visual assets (local)

Real web-sourced stock photos downloaded to this folder for the DENTORA Petra redesign. Files were fetched from Pexels image CDN URLs.

- Source platform: Pexels (https://www.pexels.com)
- License context: Pexels states its photos are free to use; verify current terms at https://www.pexels.com/license/ before commercial redistribution. No attribution is required by Pexels, but source tracking is kept here.
- Usage in this demo: local static assets only (`/assets/images/*`), lazy-loaded below fold where applicable, `object-fit: cover`, descriptive alt text, and graceful fallbacks. Dentist portraits and transformation visuals are **fictional demo content** and must not be presented as real clinic staff or real patient outcomes.
